2. ORQUESTRADOR LOCAL DE CI (scripts/ci_local.py)
-------------------------------------------------------------------------------
Para permitir que a equipe discente valide deterministicamente as 4 etapas de 
integração contínua antes de qualquer envio ao repositório remoto, foi 
implementado o orquestrador multiplataforma scripts/ci_local.py, que executa:
1. python -m compileall -q backend/src backend/main.py
2. python -m pytest -v --junitxml=reports/pytest-results.xml
3. npm run typecheck (tsc --noEmit)
4. npm run build (vite build)

3. ESTRUTURA EM CAMADAS DO BACKEND (CLEAN ARCHITECTURE)
-------------------------------------------------------------------------------
O backend foi arquitetado com separação estrita de conceitos e dependências 
apontando exclusivamente para o centro (Domínio):

[ CAMADA 1: DOMÍNIO & REGRAS PURAS ] (backend/src/domain/models.py)
  - Entidades de Domínio: Student, Teacher, Parent, Classroom, Assessment, Grade, Attendance, ReportCard.
  - Enums Fortemente Tipados: Bimester (PRIMEIRO..QUARTO), Shift (MANHA..NOITE), AssessmentType (PROVA..SEMINARIO).
  - Invariantes de Negócio: Validação algorítmica de CPF (dígitos verificadores), validação de e-mails RFC 5322, notas [0.0 a 10.0].

[ CAMADA 2: APLICAÇÃO & SERVIÇOS ] (backend/src/application/services.py)
  - ServicosDoAluno: Cálculo de médias bimestrais ponderadas por pesos, cálculo de média anual, consolidação de boletins e extratos de presença.
  - ServicosSecretaria: Matrícula de estudantes, enturmação e vinculação socioafetiva N:N de responsáveis.

[ CAMADA 3: INFRAESTRUTURA & PERSISTÊNCIA ] (backend/src/infrastructure/database.py & schema.sql)
  - Banco de Dados Relacional: SQLite 3 com 12 tabelas físicas e 11 índices de performance.
  - Padrão Repository: StudentRepository, GradeRepository, AssessmentRepository, ClassroomRepository, AttendanceRepository, AnnouncementRepository.
  - Integridade Referencial: FOREIGN KEY com ON DELETE CASCADE e restrições CHECK.

[ CAMADA 4: APRESENTAÇÃO & API RESTful ] (backend/src/presentation/server.py, controllers.py, openapi_spec.py)
  - Servidor Nativo: HTTPServer multithreaded assíncrono com suporte a CORS, roteamento dinâmico e tratamento de erros 400/404/500 em JSON (18 rotas).
  - Controladores Desacoplados: AuthController, ParentController, TeacherController.
  - Documentação OpenAPI 3.0.3: Swagger UI interativo disponível em /docs e /swagger.

4. MANUAL DE ENGENHARIA DA API RESTFUL (18 ENDPOINTS DOCUMENTADOS)
-------------------------------------------------------------------------------
[MÓDULO SISTEMA & AUTENTICAÇÃO]
1. GET  /api/health
   - Retorna o status de integridade do servidor backend e links da documentação.
2. POST /api/auth/login
   - Autentica usuários (Responsável ou Docente) e retorna token JWT mock e perfil RBAC.

[MÓDULO DO RESPONSÁVEL LEGAL - FAMÍLIA]
3. GET  /api/parent/dependents?parent_id=1
   - Retorna resumo sintético de médias, faltas e alertas dos 3 dependentes (João Silva, Ana Silva, Pedro Costa).
4. GET  /api/students/{id}/report-card?year=2026
   - Retorna o boletim escolar anual completo dos 4 bimestres com cálculo de aprovação.
5. GET  /api/students/{id}/assessments?subject=Matemática&year=2026
   - Retorna notas detalhadas por avaliação (Avaliação 1, Avaliação 2) em modo 100% somente leitura.
6. GET  /api/students/{id}/attendance?subject=Matemática&month=3&year=2026
   - Retorna extrato de frequência mensal e grade de calendário com status tátil [P], [F] e [F*].
7. GET  /api/parent/announcements
   - Retorna mural de comunicados da instituição com ordenação cronológica decrescente.
8. POST /api/parent/announcements/{id}/read
   - Confirma a leitura do aviso pelo responsável legal, sincronizando com o SQLite.

[MÓDULO DO CORPO DOCENTE - PROFESSOR]
9.  GET  /api/teacher/classes?teacher_id=1
    - Retorna escopo de turmas, disciplinas lecionadas e estudantes matriculados com matrículas.
10. GET  /api/teacher/assessments?subject=Matemática&bimester=PRIMEIRO&year=2026
    - Retorna listagem sequencial de avaliações criadas por escopo.
11. PUT  /api/teacher/assessments/{id}
    - Atualiza atributos de uma avaliação existente (título, tipo, peso, descrição) com recálculo instantâneo.
12. POST /api/teacher/assessments/add
    - Cria nova avaliação sequencial para toda a turma.
13. POST /api/teacher/grades/bulk
    - Grava em lote as notas digitadas pelo professor diretamente no SQLite.
14. POST /api/teacher/attendance/bulk
    - Grava chamada diária em lote com registro de presenças e justificativas de faltas.
15. GET  /api/teacher/announcements
    - Lista avisos e comunicados gerenciados pelo corpo docente com status de leitura pelos responsáveis.
16. POST /api/teacher/announcements
    - Cadastra e publica aviso no mural com remetente formal e tags customizadas.
17. PUT  /api/teacher/announcements/{id}
    - Edita comunicado existente previamente publicado pelo docente.
18. GET  /openapi.json
    - Especificação JSON completa da API no padrão OpenAPI 3.0.3.
